MINH HỌA POSITION TRONG CSS

1. Position: Static

Đây là vị trí mặc định của các phần tử HTML. Phần tử hiển thị theo thứ tự bình thường của trang.

BOX STATIC
Đặc điểm: Không bị dịch chuyển bởi top, right, bottom hoặc left. 
.box {
    position: static;
}

2. Position: Relative

Phần tử được dịch chuyển tương đối so với vị trí ban đầu của chính nó.

BOX RELATIVE
Đặc điểm: Hộp được dịch xuống 20px và sang phải 30px. Vị trí ban đầu vẫn được giữ lại trong bố cục. 
.box {
    position: relative;
    top: 20px;
    left: 30px;
}

3. Position: Absolute

Phần tử được định vị theo phần tử cha gần nhất có position khác static.

PHẦN TỬ CHA (position: relative)
BOX ABSOLUTE
Đặc điểm: Hộp màu cam nằm cách cạnh trên 20px và cạnh phải 20px của phần tử cha. 
.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 20px;
    right: 20px;
}

4. Position: Fixed

Phần tử được cố định theo cửa sổ trình duyệt. Khi cuộn trang, phần tử vẫn giữ nguyên vị trí.

Quan sát: Hãy cuộn trang xuống dưới và chú ý menu màu xanh ở góc trên bên phải màn hình. 
.menu {
    position: fixed;
    top: 0;
    right: 0;
}

5. Thử cuộn trang

Cuộn trang để kiểm tra hoạt động của position: fixed.
